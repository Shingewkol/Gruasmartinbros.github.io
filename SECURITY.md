# Politica de seguridad

Grúas Martín Bros agradece los reportes responsables que ayuden a proteger este sitio.

## Alcance

- Sitio público: https://gruasmartinbros.cl/
- Código y archivos estáticos de este repositorio que se publican en el sitio.

El sitio es estático y no ofrece cuentas, API propia ni almacenamiento de datos de usuarios. GitHub Pages, WhatsApp, Instagram y cualquier otro servicio externo no están bajo el alcance de esta política.

## Pruebas responsables

- Prueba únicamente el dominio y los recursos incluidos en el alcance.
- Evita denegación de servicio, spam, ingeniería social, persistencia, acceso o modificación de datos y cualquier acción que afecte a otras personas o servicios.
- No publiques detalles explotables mientras se revisa el reporte. Si encuentras datos que no deberían ser públicos, no los descargues ni los compartas; detén la prueba y avísanos.
- No realices pruebas en servicios de terceros; consulta sus propias políticas.

## Reportar una vulnerabilidad

Envía el reporte de forma privada mediante [GitHub Security Advisories](https://github.com/Shingewkol/Gruasmartinbros.github.io/security/advisories/new). Incluye la página afectada, pasos mínimos para reproducir el problema y su impacto. Comparte únicamente evidencia necesaria y redacta cualquier dato personal.

Este canal requiere que el repositorio tenga habilitada la recepción privada de reportes en sus ajustes de seguridad.

No abras un issue público para vulnerabilidades. La recepción y corrección se atenderán de buena fe, sin un plazo de respuesta garantizado.
